# FlipTok UI Design

## 專案概述

FlipTok 是一個品牌大使社群平台，整合了購物、創作、社交等功能。

### 專案規模

- **總頁面數：43 頁**（使用者/大使 29 頁 + 品牌後台 8 頁 + 管理後台 6 頁）
- **設計風格：** 現代化 UI、漸層色彩、卡片式設計
- **互動體驗：** TikTok 式全螢幕滑動、即時反饋、流暢動畫

### 角色系統

專案現已分為三個獨立的角色入口：

1. **使用者/大使端** (`user-ambassador-index.html`)

   - 一般使用者：瀏覽、購物
   - 品牌大使：創作影片、賺取收益

2. **品牌後台** (`brand-index.html`)

   - 審核大使創作內容
   - 與大使聊天溝通
   - 查看品牌收益報表
   - 管理商品與促銷

3. **平台管理後台** (`admin-index.html`)
   - 創建品牌帳號（標註創建者）
   - 管理所有品牌
   - 查看平台整體收益
   - 審核內容與用戶

## 本地開發

### 使用 Bun

```bash
bunx serve -l 5173
```

然後訪問：

- 主入口：http://localhost:5173
- 使用者/大使：http://localhost:5173/user-ambassador-index.html
- 品牌後台：http://localhost:5173/brand-index.html
- Admin 後台：http://localhost:5173/admin-index.html

## 構建

```bash
bun install
bun run build
bun run preview
```

## 使用場景

### 一般使用者

1. 註冊並觀看迎賓影片
2. 選擇喜歡的品牌與興趣標籤
3. 瀏覽內容、購買商品
4. 關注喜歡的大使

### 品牌大使

1. 購買商品後升級為大使
2. 創作品牌相關影片內容
3. 透過內容獲得收益
4. 與品牌方溝通合作

### 品牌方

1. 審核大使創作的內容
2. 與大使溝通交流
3. 管理商品與促銷活動
4. 查看銷售數據與收益

### 平台管理員

1. 創建並管理品牌帳號
2. 監控平台整體營運數據
3. 審核平台內容
4. 配置系統參數
