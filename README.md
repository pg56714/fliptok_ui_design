# FlipTok UI Design

## 專案概述

FlipTok 是一個品牌大使社群平台，整合了購物、創作等功能。

### 角色系統

專案現已分為三個獨立的角色入口：

1. **使用者/大使端** (`user-ambassador-index.html`)

   - 一般使用者：瀏覽、購物
   - 品牌大使：創作影片、賺取收益

2. **品牌後台** (`brand-index.html`)

   - 與大使聊天溝通
   - 查看品牌收益報表
   - 管理商品與促銷
   - 審核大使創作內容

3. **平台管理後台** (`admin-index.html`)

   - 創建品牌帳號
   - 管理所有品牌
   - 查看平台整體收益
   - 審核大使創作內容

## 主要功能

### 使用者/大使功能

#### 📝 註冊與登入

- ✅ 登入頁面（可先跳過，有需要用到購物或是大使功能時，本地端需提示要註冊帳號）
- ✅ 註冊頁面
- ✅ 忘記密碼功能
- ✅ 註冊後播放迎賓影片

#### 🎯 個人化設定

- ✅ 品牌選擇（可略過，但需付費解鎖完整體驗）
- ✅ 興趣標籤選擇
- ✅ 付費解鎖完整體驗 (付費方案待確定)
- ✅ 首次購買綁定信用卡，後續一鍵下單

#### 🏠 內容瀏覽

- ✅ 首頁 Feed（TikTok 式全螢幕直式滑動）
- ✅ 商品彈跳視窗（Add to Bag / Buy Now）
- ✅ 品牌 Logo 點擊進入品牌主頁
- ✅ 大使頭像點擊進入大使主頁
- ✅ 探索頁面（搜尋、熱門標籤、推薦關注、熱門內容）

#### 🎬 創作功能

- ✅ 權限控制：只有大使能創作
- ✅ 影片拍攝編輯工具（限制 60 秒，含濾鏡、剪輯、文字、貼圖等等）
- ✅ 上傳影片需品牌或平台審核

#### 👤 個人中心

- ✅ 編輯個人資料（點擊頭像）

  - 更新聯絡資訊（Email、手機）
  - 修改密碼（安全驗證）
  - 帳戶管理（停用/刪除帳戶）
- ✅ 關注名單管理（附取消關注功能）
- ✅ 邀請好友功能
- ✅ 排行榜（週/月/年度）
- ✅ 品牌中心（品牌一覽）
- ✅ 問卷調查（在設定中，填寫送購物金）
- ✅ 粉絲影響購買通知
- ✅ 語言設定
- ✅ 登出功能

#### 👑 大使功能

- ✅ 購買後可晉升為品牌大使
- ✅ 選擇品牌直接付費，無需審核
- ✅ 大使聊天室（與品牌溝通）
- ✅ 數據分析（作品表現與收益）

#### 🛍️ 購物功能

- ✅ 購物車管理

## 本地開發

### 使用 Bun

```bash
bunx serve -l 5173
```

- 主入口：http://localhost:5173
- 使用者/大使：http://localhost:5173/user-ambassador-index.html
- 品牌後台：http://localhost:5173/brand-index.html
- Admin 後台：http://localhost:5173/admin-index.html

## 構建

```bash
bun install
bun run build
bun run preview
```
