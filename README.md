# FlipTok UI Design

## 專案概述

FlipTok 是一個品牌大使社群平台，整合了購物、創作等功能。

### 角色系統

專案現已分為三個獨立的角色入口：

1. **使用者/大使端** (`user-ambassador-index.html`)

   - 一般使用者：瀏覽、購物
   - 品牌大使：創作影片、賺取收益

2. **品牌後台** (`brand-index.html`)

   - 與大使聊天溝通
   - 查看品牌收益報表
   - 管理商品與促銷
   - 審核大使創作內容

3. **平台管理後台** (`admin-index.html`)

   - 創建品牌帳號
   - 管理所有品牌
   - 查看平台整體收益
   - 審核大使創作內容

- ✅ 權限控制：只有大使能創作（需要擋住一般使用者）

撥款流程：

```
訂單完成 → 平台結算（扣除 15% 平台抽成 + 2.5% 金流費）
        ↓
   品牌收到撥款通知
        ↓
   預計撥款日期（通常 7-14 天）
        ↓
   款項匯入品牌帳戶
```

```

           ↓
平台撥款給品牌（扣除平台抽成 15%）
```

## 本地開發

```bash
bunx serve -l 5173
```

- 主入口：http://localhost:5173
- 使用者/大使：http://localhost:5173/user-ambassador-index.html
- 品牌後台：http://localhost:5173/brand-index.html
- Admin 後台：http://localhost:5173/admin-index.html

## 構建

```bash
bun install
bun run build
bun run preview
```
